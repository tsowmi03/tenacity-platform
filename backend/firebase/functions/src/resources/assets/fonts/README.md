# Diagram label fonts

DejaVu Sans 2.37 (regular, bold, oblique, bold oblique), used by
`../../diagramFonts.js` for diagram labels.

The Cloud Functions image has no font that places combining marks (the bar in
x̄, the dot of a recurring decimal) over the letter before them, so those
labels printed with the mark floating beside the letter (RES-40). These files
ship with the functions so the result does not depend on what the image has
installed.

(https://dejavu-fonts.github.io/License.html).
